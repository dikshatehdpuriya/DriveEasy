# 🚗 DriveEasy

DriveEasy is a simple car rental website built with HTML, CSS and JavaScript.

🔗 **Live Demo:** https://dikshatehdpuriya.github.io/DriveEasy/

## Features

- Search cars by name, brand or fuel type
- Filter by price, brand, fuel and transmission
- Sort cars by price or name
- View car details in a popup
- Booking form with an estimated total
- Contact form
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository
   ```
   git clone https://github.com/dikshatehdpuriya/DriveEasy.git
   ```
2. Open `index.html` in your browser

## Note

The booking and contact forms are for demo only. No data is stored or sent anywhere.
